# Revenue & Payout Logic

- **The Take-Rate:** Platform keeps 5% + SSLCommerz gateway fee (~2%).
- **Escrow Buffer:** Money stays in "Pending" for 120 minutes post-session.
- **Manual Payout:** Minimum ৳500 withdrawal.
- **Anti-Money Laundering:** A user cannot withdraw money they deposited (Student Wallet). Only "Earned" money (Tutor Wallet) is withdrawable.
